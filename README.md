# 🤖 AI Job Recommendation System

An intelligent, machine learning-powered job recommendation application that helps candidates identify relevant job opportunities based on their skills and resume information.

The application analyzes candidate profiles, evaluates skill compatibility, and presents relevant job matches with match scores and skill-gap insights.

## ✨ Key Features

- 📄 **Resume Upload:** Upload resumes in PDF and DOCX formats.
- 🎯 **Job Matching:** Evaluate compatibility between candidate skills and job requirements.
- 📊 **Match Score:** View job matching scores to understand profile relevance.
- 🧩 **Skill Coverage:** Identify how well your skills align with job requirements.
- ✅ **Matched Skills:** Discover skills that match the job requirements.
- ⚠️ **Missing Skills:** Identify skills that may need improvement.
- 🌐 **Interactive Interface:** Simple and accessible Streamlit web application.

## ⚙️ How It Works

1. **Upload Resume:** The user uploads their resume.
2. **Text Extraction:** The application extracts relevant information from the uploaded document.
3. **Skill Analysis:** Candidate skills are identified and compared with job requirements.
4. **Job Matching:** The system evaluates compatibility between the candidate profile and available job requirements.
5. **Results:** The application displays match scores, skill coverage, matched skills, and missing skills.
